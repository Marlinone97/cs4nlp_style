## Context-Aware Dialogue Style Transfer in Non-parallel Political Conversations (Alice, Luca and Cem)

### Baseline folder

This folder contains the notebook used to compute our baseline outputs for a given dialogue using prompting-based style transfer.

### Cem files folder

### Evaluation folder

This folder includes an example implementation of the cosine similarity method used to evaluate content preservation between original and rewritten utterances.

### kasdg results folder

This folder contains the results of our attempt to run the KASDG model on a small sample of their data.

### model 1 folder

This folder contains the full codebase and training data for Model 1, our dual-cycle BART-based style transfer model.

### model 2 folder

This folder contains the code for Model 2, including few-shot prompting logic integrated with topic guidance.

### topic modeling folder

This folder contains the code used to perform topic modeling with LDA to cluster dialogues by theme and support topic-aligned style transfer.
